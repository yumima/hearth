Local AI engine

Local models fitted to the hardware (GPU, VRAM, RAM), verified and served over an OpenAI-compatible API. Chat window, coding agent, voice, web search, MCP tools. Free to use, 100% local, no signup. Open models (Qwen) on Ollama. Linux, Windows, macOS.

Install

Linux (x86-64), macOS (Apple Silicon):

curl -fsSL https://yumima.github.io/hearth/install.sh | sh

Windows (PowerShell):

irm https://yumima.github.io/hearth/install.ps1 | iex

Per-user, single folder, no administrator rights. Existing Ollama, Python and hearth installations are not modified. Disk: engine up to 2 GB, model 3–18 GB. Install script.

Setup

The setup page (http://127.0.0.1:11435/) ranks models by hardware fit. The selected model is downloaded, verified against the tested build, loaded with the largest context that stays on the GPU, benchmarked and checked before use.

API

OpenAI-compatible, at http://127.0.0.1:11435/v1: chat completions (streaming, tool calls), embeddings, models. finterm detects it automatically and asks before connecting.

Clients

  • Chat window (Hearth in the app menu) — MCP tools, voice input and output, language tutor. Skip with --no-client.
  • Coding agent (hearth in a folder) — reads files; asks before edits, commands and web access.

Update and uninstall

hearth update installs the latest release and rolls back if it does not start. hearth uninstall removes hearth; --keep-models keeps the models.
